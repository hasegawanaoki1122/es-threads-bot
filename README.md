# 株式会社ES Threads 自動投稿

## しくみ
- `posts/schedule.json` に書いた投稿を、予定時刻になると自動で投稿します（30分ごとに確認）。
- 投稿した記録は `data/history.json` に残ります。同じIDや同じ本文は二度投稿しません。
- 毎週月曜9時に、閲覧数などを `data/insights.csv` に保存し、`reports/` に週次レポートを作ります。

## 一時停止したいとき
- **全部止める**：GitHubの「Actions」→「投稿」→ 右上の「…」→「Disable workflow」
- **再開する**：同じ場所の「Enable workflow」
- **1本だけ止める**：その投稿に `"skip": true` を足す（Claudeに頼んでOK）

## 失敗したとき
- GitHubから登録メールアドレスに「Run failed」というメールが届きます。
- そのメールの内容をClaudeに伝えてください。

## 問い合わせ・契約の記録（ここは手で入力）
- `data/results.csv` に1件1行で入力します。
- 「きっかけの投稿ID」には、お客様に「どの投稿を見ましたか？」と聞けたときに、その投稿のIDを入れます。分からなければ空欄で大丈夫です。
- 「契約」の欄は、契約したら「はい」と入れます。
